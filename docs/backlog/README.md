# SPP Factory Build Backlog (`docs/backlog/README.md`)

This directory contains the ordered **AI Software Factory ("Dark Factory") build backlog** for the **Self-Service Provisioning Platform (SPP)** on **Google Cloud Platform (GCP)** (`us-east1`).

All specifications, architectural invariants, data models, naming/label rules, and four-gate examples trace directly to the canonical upstream source of truth in **[`github.com/vaishnavi4068/ssp-doc`](https://github.com/vaishnavi4068/ssp-doc)** (`main`) and are executed by the **SPP AI Software Factory** in **[`github.com/vaishnavi4068/spp-factory-foundation`](https://github.com/vaishnavi4068/spp-factory-foundation)** (`main`).

---

## 1. Non-Negotiable Platform & Backlog Guardrails

1. **Cloud & Region Scope (`ADR-GLB-001`, `ADR-GLB-007`, `ADR-CLD-GCP-001`):**
   - **GCP only** (`cloud = "gcp"`). Other clouds are out of scope.
   - **Region `us-east1` only** (`location = "us-east1"`, Spanner `config = "regional-us-east1"`, KMS keys in `locations/us-east1`) across both `nonprod` and `prod` (no multi-region `US` or `nam3`, no `us-east4`).
2. **Environment Taxonomy (`ADR-GLB-006`, `ADR-GLB-008`, `ADR-BP-003`):**
   - Only two environments exist: **`nonprod`** (no hyphen) and **`prod`**.
   - Legacy environment codes (`sandbox`, `dev`, `qa`, `test`, `pdev`, `pqa`, `preprod`) all normalize to **`nonprod`** everywhere (including the Spanner `dbaas_reviewer` skip condition).
   - The legacy `environmentsubtype` label is **dropped everywhere**; `environmenttype` (`nonprod` | `prod`) is one of the **8 mandatory labels** (`sppappid`, `costcenter`, `environmenttype`, `primarylob`, `datasensitivity`, `owner`, `provisionedby`, `idp_resource_id`).
3. **Four-Gate Provisioning Model (`ADR-GLB-003`, `ADR-GLB-004`):**
   - **Gate 1 (`Requested`) & Gate 2 (`Approved`):** Stored in full in **Google Cloud AlloyDB for PostgreSQL** (`spp_platform` database, schema `idp`, 18 tables + `idp.v_resource_status` view from `specs/data-model/spp_state_model.sql`) with **zero secret values (`INV-1`)**.
   - **Gate 3 (`Expected`) & Gate 4 (`Observed`):** Artifacts (`expected/rev-NNNNNN/{terraform.tfvars.json, manifest.json, plan.json}`, `default.tfstate`, `observed/scan-<window>/plan.json`) stored in the single GCS bucket **`gs://<spp-factory-host-project-id>-spp-tfstate`** in `us-east1` under `projects/<project_id>/` (one state unit = one GCP project = one state file, `INV-8`). AlloyDB stores only pointers, canonical SHA-256 hashes, `plan_summary` counts, `<= 2 KB` (`< 2000` bytes) non-sensitive `idp.resource_observed.projection` rows, and `idp.drift_finding` summaries.
4. **Never Destroy GCP Infrastructure Without Human Approval (`ADR-GLB-004`, `ADR-GLB-007`, `ADR-BP-003`, `ADR-AUT-002`):**
   - Nothing is deleted, destroyed, or replaced without explicit human approval in **any** environment (`nonprod` or `prod`).
   - `AUTO_APPROVED` / `auto_approved` is strictly forbidden when `action = 'delete'` or when a Terraform plan has `destroy > 0` or `replace > 0` (`blocked_reason = 'destroy_without_delete_request'`).
   - Never force-destroy non-empty buckets (`force_destroy = false` via `GCS-DEL-001` and `SPN-DEL-001`).
   - Never destroy existing GCP infrastructure.
5. **Alert-Only Drift (`ADR-GLB-007`, `ADR-AUT-002`):**
   - Drift detection compares `Observed` against `Expected` and is **strictly alert-only** (`status = 'OPEN'`). The platform never auto-remediations or auto-reapplies; remediation requires a new human-approved request (` rollback` re-applies the last approved spec via a new revision).
6. **Sanitization & Placeholder Discipline:**
   - Use **`SPP`** only (no company, enterprise, or internal vendor names).
   - Commit **zero secrets**, **zero real KMS key paths**, and **zero employee IDs**.
   - Never invent unconfirmed environment values; mark all pending user-supplied values explicitly as **`TODO`**.

## 3. Factory Assembly Line Reference (`spp-factory-foundation`)

Each work item in this backlog is executed by the **SPP AI Software Factory** (`WorkItemWorkflow` on the `factory` Temporal namespace in the SPP GKE cluster, K8s namespace `spp-factory`) across **8 sequential stations**, where a single unified coding agent (`@google/gemini-cli` on Vertex AI `gemini-2.5-pro`) dynamically loads the station's role skill from `agents/skills/<role>/SKILL.md` (`ADR-AUT-003`):

| Station # | Station ID | Loaded Role Skill(s) (`agents/skills/<role>/SKILL.md`) | Execution Mode & Gate Rules |
| :--- | :--- | :--- | :--- |
| **Station 1** | `impact` | `requirements-impact` | Analyzes governing ADRs in `ssp-doc` and produces an Impact Assessment Report across schemas, Rego policies, and product repos. |
| **Station 2** | `plan` | `change-plan` | Produces a deterministic Execution Change Plan mapping every `REQ-*`, `GR-*`, and `SC-*` to automated tests. *(Phase 1 human gate unless `auto_advance`.)* |
| **Station 3** | `build` | `control-plane`, `iac-module`, `policy-and-compliance`, `portal-and-catalog` | Implements code, migrations, Rego policies, Terraform modules, and tests in sandboxed K8s Job `factory-wi-<id>-build-<attempt>`. |
| **Station 4** | `gate` | `validation` | Runs `gates/scripts/run_gate.sh` (7 stages). Loops back to `build` up to **3 retries** (`MAX_REWORK_RETRIES = 3`) before transitioning to **`BLOCKED`**. |
| **Station 5** | `review` | `change-review` | Audits the git diff against all guardrails (zero secrets, CMEK, `us-east1`, human delete approval, `TODO` placeholders) and prepares the PR review summary. |
| **Station 6** | `approval` | Human Gate (`change-review` package) | **Permanent human gate** in Phase 1/2 (`Manoj` [Architect], `Dwayne` & `Norm` [Approvers]). |
| **Station 7** | `merge` | `control-plane` | Merges the approved PR into the target repository's base branch. |
| **Station 8** | `reconcile` | `drift-and-reconciliation` (+ `standards-feedback`) | Verifies post-merge state/drift reconciliation and feeds lessons learned back into ADRs, Rego rules, and skills. |
